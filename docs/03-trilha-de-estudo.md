# 03 · Trilha de estudo

Seis guias, nesta ordem. Todos vêm do Internet Archive ou dos próprios mantenedores das ferramentas. (A tabela abaixo espelha `data/tools.json`.)

| Ordem | Guia | O que aprender | Tempo sugerido |
|---|---|---|---|
| 1 | [Using the Wayback Machine](https://help.archive.org/help/using-the-wayback-machine/) | Navegação, capturas, limitações | 30 min |
| 2 | [Save Pages in the Wayback Machine](https://archivesupport.zendesk.com/hc/en-us/articles/360001513491-Save-Pages-in-the-Wayback-Machine) | Save Page Now e extensões | 20 min |
| 3 | [Wayback Machine APIs](https://archive.org/help/wayback_api.php) | Availability API | 20 min |
| 4 | [CDX Server API](https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server) | Datas, filtros, campos, dedup, paginação | 1–2 h |
| 5 | [Waybackpy](https://akamhy.github.io/waybackpy/) | APIs via Python e terminal | 1 h |
| 6 | [Wayback (EDGI)](https://wayback.readthedocs.io/en/stable/) | Pesquisa e recuperação em scripts | 1 h |

## Como estudar (em vez de só ler)

1. **Escolha um alvo seu**, seguro e legítimo: o seu próprio site antigo, um projeto de código aberto, um órgão público com página que já mudou.
2. A cada guia, **produza um artefato**: uma URL de captura anotada (1–2), uma resposta da Availability API (3), um CSV de CDX (4), um script (5–6).
3. Mantenha um caderno com as perguntas: *o que este resultado prova? o que não prova?*

## Depois da trilha

Faça os [quatro exercícios](04-exercicios.md). Instalar muitas ferramentas que coletam a mesma coisa ensina menos do que percorrer o ciclo completo uma vez: **recuperar → inventariar → comparar → documentar**.
